Port loop: success rate per model

Parts of the T32 and T33 kernel driver are ported from the recovered vendor code by a loop that asks a language model for the port and runs a host test on it. This page shows how often each model's attempt passed that test: passes divided by attempts, with the attempt count next to every bar. 213 attempts in total, 2026-11-09 to 2026-11-14. Counts and rates only.

Escalation rule. Cheap first, one try per model: DeepSeek only for small blocks (about 3 functions or fewer), then Claude Sonnet, then Claude Opus, then Claude Fable. A model never gets a second try on the same block; the next model starts from the files the previous one left behind.

The T32 waves before this rule was set ran DeepSeek on larger blocks too, which is why the large-block DeepSeek bars are mostly failures.

How the numbers were counted

  • One attempt is one run of the loop tool for one block of functions with one model; every run is counted, including re-runs of the same block (T32 ran more than one wave before the one-attempt-per-model rule existed).
  • A DeepSeek run starts on Flash and moves to Pro inside the same run when the Flash rounds do not go green. So a run that escalated is counted twice: one failed Flash attempt and one Pro attempt with the result of the run. Flash passes are runs that went green on Flash alone; Pro attempts are every run that reached Pro, or started there for long reference code.
  • Pass means the host test of the block went green (our C against the vendor code). Failed means it never did. An independent review of a passing T32 oracle sometimes listed gaps; those were closed by follow-up fixes, so the attempt stays a pass (the count is in the table view). No attempt is recorded as rejected in review.
  • Follow-up runs that fix review gaps (T32) and the T32 runs of new blocks are included; follow-up runs have no function count and appear under "size not recorded".
  • 2 attempts could not be assigned to a charted model (the log does not say whether a DeepSeek pass came from Flash or Pro, or the model is not recorded). They are not charted and not guessed.
