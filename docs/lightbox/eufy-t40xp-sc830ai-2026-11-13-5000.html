Method

  • Same camera, same chart position, same lamps; open stack first, then the vendor ISP module + vendor libimp are loaded from /tmp (nothing flashed); the camera returns to the flashed image at the end (module reload or reboot).
  • P1 = camera defaults (AE, AWB, comp 128). P2 = matched exposure: the same integration time and gains on both stacks, set inside the streamer and read back from the ISP; rows whose read-back differs are marked verify=FAIL and not compared.
  • A/A: point p2_a is measured twice (p2_a, p2_a2); the relative difference is the repeatability of the method. A difference between the stacks counts only beyond 2 x that spread (floor 5 %).
  • NV12 noise is measured on raw NV12 frames from the streamer (no JPEG in the path): temporal standard deviation per pixel over the burst, mean over Y 32..224, and U/V.
  • Colour: SpyderCheckr 24 detected automatically, sRGB -> Lab (D50), CIEDE2000 against the Datacolor default values (D50 assumed, not batch specific); 'grey-normalised' removes the white-balance cast first.
  • Sharpness: slanted-edge method on the chart's outer patch edges, frames averaged against noise; JPEG snapshot path.
  • SSIM/PSNR (when run): both stacks record the same static chart scene at the same bitrate; each stream is decoded and compared against a high-bitrate capture of the SAME stack (reference), so the number is the encoder loss of that stack; a cross-stack comparison on static frames is listed separately and includes the ISP difference.
  • Encoder (A5): both stacks get the same timps settings (codec, rc_mode, qp / bitrate, gop) through a /tmp conf and a streamer restart; the recordings come over RTSP (ffmpeg -c copy). The reference is a mean image, because single NV12 frames are not frame-aligned with the stream; the scene is static, so every decoded frame can be compared with it. A second reference at the end of the phase shows whether the scene or the AE moved in between.
  • Lamp switches are made by a person on a marker (NEED_* file); the times above are the marker times.
